## $(date +%Y-%m-%d) - Caching layout metrics to prevent scroll thrashing
**Learning:** In a long single-page application with multiple scroll-linked effects (scroll spy navigation and parallax elements), reading layout metrics like `offsetTop` and writing to `style.transform` inside the same high-frequency `scroll` event handler causes severe layout thrashing (forced synchronous layout).
**Action:** Always separate DOM reads from writes. Cache layout dimensions (`offsetTop`, element bounds) on `load`/`resize` and use a `ResizeObserver` to catch dynamic content shifts. Use cached values in the scroll handler to determine state, and only write to the DOM (e.g. `classList.add`) when the state actually changes. Apply visibility checks (using cached bounds) to skip expensive calculations (like `transform`) for elements that are currently off-screen.
