## 2024-05-18 - Retrofitting Interactive Cards for Keyboard Accessibility\n**Learning:** This project uses non-button interactive elements like `div`s with `onclick` attributes or `.carousel-slide` that cannot be triggered by the keyboard. This breaks keyboard navigation completely.\n**Action:** Add `role="button"`, `tabindex="0"`, and attach a `keydown` event listener to trigger the click method upon Enter/Space presses on these elements. Initialize `aria-expanded` and track it dynamically to match visual expansion.
